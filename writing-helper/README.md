# Writing Helper

Write or rewrite any text — docs, emails, articles, stories, reports — with always-on surgical correction and humanize.

## Quickstart

Load the skill in an agent session. The skill will:
1. Infer format, tone, audience, and purpose from your request
2. Confirm the plan with a structure proposal (inline or file path)
3. Generate output with surgical correction + tone match + humanize
4. Loop on revisions until you say "looks good"

## Reference Files

Correction rules, tone definitions, and humanize guidelines are inlined in `SKILL.md`.
