# Grammar Correction — Minimal Change Principle

Always applied as a mandatory baseline layer before tone/style and anti-detection polish.

## Core Rule: Fix Only What's Wrong

If the phrasing is grammatically legal but clunky, leave it. Never rewrite for "flow," "clarity," or "professionalism" at this stage.

## What to Fix

### Mechanics
- Spelling typos and misspellings
- Capitalization (sentence starts, proper nouns, "I")
- Punctuation errors (comma splices, apostrophes, homophones like their/they're/there, its/it's)

### Agreement
- Subject-verb agreement (e.g., "The list of items are..." → "The list of items is...")
- Pronoun-case agreement (e.g., "Him and me went" → "He and I went")
- Accept singular "their" for "everyone/someone" to avoid structural rewrites

### Word Usage & Verbs
- Wrong prepositions (e.g., "interested on" → "interested in")
- Incorrect word pairs (affect/effect, fewer/less, then/than)
- Non-standard irregular verb forms (e.g., "I have went" → "I have gone")
- Tense inconsistency within a single narrative thread

### Logic
- Misplaced modifiers only if they cause factual misunderstanding

## What NOT to Touch

- Passive voice → active voice conversions
- "Due to the fact that" → "because"
- Valid redundancies ("very, very")
- Clunky lists or lack of parallel structure (unless a hard error)
- Style, flow, or narrative flair

## Output

Return only the corrected text. No commentary, no markdown bolding of changes, no "Here is the corrected text." If no errors found, return the text exactly as provided.
