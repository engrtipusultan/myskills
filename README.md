# My Skills

A collection of agent skills developed for structured, human-in-the-loop workflows.

## Skills

- **BrainstormWithMe** — Cross-domain brainstorming skill. Guides structured design before any action, for code projects, life decisions, or creative work.
- **Shakedown** — RED-GREEN-REFACTOR testing methodology for validating agent skills against adversarial scenarios on local models.

## Usage

Each skill is self-contained in its folder with a `SKILL.md` (the skill itself) and `README.md` (quickstart). Load the skill in an agent session and follow its checklist.
